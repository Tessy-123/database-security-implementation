Project Overview

This application demonstrates core database security defenses designed to mitigate common web vulnerabilities such as SQL Injection, broken authentication, and unauthorized data exposure. Built as part of final-year undergraduate security requirements[cite: 1].

Authentication

Secure credential handling using salted password hashing via Web Crypto API.

Parameterised Queries

Complete prevention of SQL injection through prepared statements.

Access Control

Role-Based Access Control (RBAC) separating Admin and Standard User privileges.
