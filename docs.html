Security Mechanisms Implemented

  • One-Way Hashing (SHA-256): Passwords are transformed into irreversible cryptographic digests via Web Crypto API digest algorithm prior to storage.
  • Dynamic Data Masking: Sensitive identifiers (e.g., National ID numbers) hide all but the trailing four characters to prevent unauthorized eavesdropping.
  • Privilege-Gated Decryption: Full unmasked raw data access is denied across public endpoints and accessible strictly under explicit DB administrator key escalation.
