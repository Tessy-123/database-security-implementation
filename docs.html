2. Implemented Security Controls

  • User Authentication: Passwords are processed using cryptographic hashing routines via the Web Crypto API, mitigating plain-text interception risks.
  • Access Privileges (RBAC): Strict separation between Standard User and Administrator roles, restricting unauthorized execution of administrative functions.
  • Parameterised Queries: Separation of executable code and user-supplied parameters to completely neutralize SQL Injection (SQLi) vectors.
  • Input Validation: Strict schema validation and sanitisation filters applied on all input fields prior to database operations.
  • Sensitive Information Protection: Data masking and tokenization applied to secure personally identifiable information (PII).
